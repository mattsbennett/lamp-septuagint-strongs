# Provenance

What went into the tagged text, where each part of a tag comes from, and what was deliberately kept
out.

## Inputs

| Input | What it is | Terms | Version |
|---|---|---|---|
| `data/source/LXX.json` | Brenton's Greek Septuagint (1851), the 39 books of the Hebrew canon | Public domain | eBible.org `grcbrent` USFM, source files dated 8 April 2026, obtained 4 November 2026. Zip SHA-256 `5b777b54…184aca`; converted file SHA-256 `31e0a963…51ea74f` |
| TAGNT | STEPBible's tagged Greek New Testament | CC BY 4.0 | STEPBible-Data commit `5de0a47f35f0` (2 November 2026) |
| TBESG | STEPBible's Greek lexicon with extended Strong's numbers | CC BY 4.0 | same commit |
| TAHOT | STEPBible's tagged Hebrew Old Testament | CC BY 4.0 | same commit |
| TBESH | STEPBible's Hebrew lexicon | CC BY 4.0 | same commit |
| `data/source/versemap_lxx_to_english.json` | Septuagint verse numbers mapped to English ones | MIT (SIL) | computed from SIL libpalaso's versification tables, commit `b4f7a6da7b86` |

Full checksums are in `scripts/fetch_sources.py` and `data/MANIFEST.json`.

The STEPBible files are not in this repository. STEPBible asks that copies not be posted elsewhere,
so `scripts/fetch_sources.py` downloads them from STEPBible's repository at the pinned commit and
checks each against its recorded checksum.

### About the Greek text

- It is the Greek that Brenton printed beside his translation, which follows the Sixtine edition
  of 1587 and so, in the main, Codex Vaticanus. It is not a critical text. Where it differs from
  Rahlfs or the Göttingen editions, the tags describe Brenton's words.
- **Books.** The 39 books of the Hebrew canon. Ezra and Nehemiah are one book of 23 chapters
  (2 Esdras), as Brenton prints them, so there are 38 files. Esther and Daniel include their Greek
  additions; Daniel is Theodotion's version. The other books Brenton prints (Tobit, Judith, Wisdom,
  Sirach, Baruch, the Letter of Jeremiah, Susanna, Bel, 1–4 Maccabees, 1 Esdras, the Prayer of
  Manasseh) are **not included**.
- **Lettered verses** are merged into the numbered verse they follow: 3 Kingdoms 12:24a–z is part
  of 12:24, and Esther's additions are part of the verse they follow.
- eBible.org does not say who digitised the text. A small number of words look like digitisation
  errors (see [GAPS.md](GAPS.md)).
- The USFM was converted to `LXX.json` by the Lamp Bible app's own importer, which is not in this
  repository. The converted file is, and its text is the input the tags are aligned to.

## Where each part of a tag comes from

| Part | Source |
|---|---|
| The word, its position | Brenton's text, unchanged |
| Greek Strong's number and dictionary form | The New Testament form's entry in TAGNT, or the lexicon entry in TBESG. Never invented: a word whose dictionary form STEPBible does not list is left untagged |
| Parse | For a form the New Testament uses, TAGNT's code for it. For a form it does not, the code generated by this project's analyser from the lexicon entry's paradigm. Always a code TAGNT itself uses |
| Which reading, where there are several | This project's statistical model, trained on TAGNT only |
| Hebrew Strong's number on a name | The name STEPBible's TAHOT tags in the corresponding Hebrew verse, matched by this project's transliteration model |
| Confidence | Measured on held-out New Testament text (words) and on held-out name pairs from TBESG (names) |

Every row of the tables under `data/tagged/` records its own source, the method that chose it, the
other readings considered and the confidence.

## What was kept out

The older tagged Septuagints all descend from one analysis, the CATSS/CCAT morphologically analysed
Septuagint, whose user declaration forbids commercial use and passing the data on without the
owners' consent. This project set out to make a tagging that owes nothing to it. The rules:

1. **No tag source but the inputs above.** No tagged Septuagint, and nothing derived from one, was
   read by the tagger: not CCAT, not the Apostolic Bible Polyglot, not a treebank, not a model
   trained on any of them.
2. **No share-alike or NonCommercial inputs either.** Morpheus, Wiktionary, the Perseus lexica and
   the Ancient Greek treebanks were not used, so the result needs nothing but STEPBible's credit.
3. **Reference taggings were used to measure, and for nothing else.** Four of them (CCAT, the
   Apostolic Bible Polyglot, the PTNK treebank, GLAUx) were compared with the finished tags to
   produce the figures in [SCORES.md](SCORES.md). That was done privately, within their terms.
4. **The measuring code is separate from the tagging code.** The scoring programs
   (`validate_ccat.py`, `validate_refs.py`, `ccat_*.py`, `ref_*.py`) are the only code that reads a
   reference. The tagger does not import them, and they write nothing the tagger reads.
5. **Half the books were held back.** The books were divided once, when the scoring programs were
   written, into a development half and a test half. For the test half the scoring programs print totals only.
   While the tagger was being improved, only totals and error-class counts from the development
   half were looked at (for example "neuter nominative taken for accusative: 3,460 words"), to
   decide which part of the grammar to work on next. The scoring programs can also
   print a few sampled disagreements from the development half, showing our own tag and the kind of
   difference only ("case differs: ours genitive, theirs dative"), never the reference's dictionary
   form or parse. Those samples were read when writing the scoring programs, to decide which
   differences are naming conventions and which are real, and were not used in the work on the
   tagger.
6. **Nothing from a reference is published.** No reference text, no reference tag and no
   word-by-word comparison is in this repository; only totals are.

What this does and does not establish: no tag was copied from or trained on a reference. The
choice of which *kinds* of error to work on was informed by totals from the development half, so
the development-half figures are not a blind test. The test-half figures are.

## Rebuilding

```sh
./build.sh
```

It fetches STEPBible's files, tags the text and rewrites `data/`, then checks that what it wrote
matches what is committed. It needs Python 3 (built and tested with 3.13) and no packages. The
first run trains the model, which takes several minutes on four cores; the result is cached under
`.cache/`. The same inputs give the same bytes.

The scoring programs are included so the method can be read and rerun, but they need the reference
taggings, which you must obtain yourself under their owners' terms (for CCAT, its signed user
declaration).
